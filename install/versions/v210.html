Avogadro 2.1.0#

23 October 2026

Thanks to everyone who made suggestions, bug reports, translations, and discussions. Avogadro is built from the community, and we appreciate all the help.

Avogadro v2 was designed as a platform to make it easy to build the next generation of molecular and materials visualization, including fast modern rendering and improved stability. With this release, we mark 30 plugins and will offer tutorials on making your tools easily available as plugins.

🌟 Highlights (tldr)#

  • New Z-matrix editor: view and edit internal coordinates, including constraints, dummy atoms for linear molecules, and drag-and-drop to reorder atoms. Input generators can now write Z-matrix coordinates.

  • Faster, smoother geometry optimization using the ABC-FIRE method and a hybrid mode that is now the default for Optimize and AutoOpt.

  • Much faster orbitals and surfaces: Gaussian basis set calculations are up to 20-25× faster, large ORCA files load much faster too.

  • Improved conformer and dynamics plot including geometry parameters, velocities, temperature, etc.

  • Batch energies and forces: recalculate energies and forces for every conformer or frame at once, in batches suited to ML potentials.

  • New building tools

    • An initial polymer builder - feedback welcome

    • D-amino acids in the peptide builder.

    • Edit distances, angles, and dihedrals directly in the Measure tool.

    • PDB biological assemblies (tested to ~1 million atoms).

    • Fractional supercells.

    • Better support for CIF files, including space group perception from transforms.

  • New camera controls: virtual trackball rotation for all tools, keyboard shortcuts for rotating, and click-and-drag to focus on an atom.

  • Custom properties: atom, bond, residue, and conformer properties are kept and can be viewed and edited in the property tables.

  • Better vibrations: each step of an optimization or scan can now have its own vibrations, displaced geometries can be generated, and ORCA symmetry labels are read.

  • Scripting and automation

    • Many tools can now be controlled through a JSON-RPC interface, including selection, measurement, force fields, constraints, symmetry, spectra, colors, and hydrogens.

    • The avogadro.connect Python module can now list the available commands, making it easy to drive Avogadro from Jupyter, scripts, or AI agents.

    • A new avogadro-mcp project for connecting local LLM models and agents to Avogadro.

  • Transparent compression support read and write compressed files directly (e.g., .gz, .xz and .zstd).

  • Plugin improvements: progress bars and a cancel button for plugin scripts, plus authors, download counts, and bug tracker links in the plugin window. Installs are more reliable.

  • More stable: continuous fuzz testing on Linux and Windows found and fixed a large number of bugs and potential crashes in file readers and editing.
